# 💬 Distributed Chat Application

A real-time distributed chat application developed using Java RMI.

## 📌 Features

- User authentication
- Account creation
- Online users
- Private messaging
- Broadcast messaging
- Message history
- MySQL database
- Java Swing interface

## 🛠️ Technologies

- Java
- Java RMI
- Swing
- MySQL
- IntelliJ IDEA

## 🏗️ Architecture

Client → RMI → Server → MySQL
